# 🌐 SIS-FP Project – Landing Page de Calidad del Software

### 🚀 Proyecto Formativo SENA – Aplicación de Buenas Prácticas de Calidad

Esta Landing Page ha sido desarrollada como parte del proceso de **documentación y aplicación de buenas prácticas de calidad** del sistema **SIS-FP Project**, una solución tecnológica creada para optimizar la **gestión y el control de seguridad portuaria** en entornos industriales.

La página presenta la estructura, metodología, y resultados del proceso de implementación de calidad del software desarrollado, integrando los elementos solicitados por el componente formativo **"Fundamentos de calidad de software"**.

---

## 🧩 Descripción del Proyecto

**SIS-FP Project** es un sistema integral que gestiona:
- Registro y control de empresas que operan en el puerto.  
- Control vehicular y de embarcaciones.  
- Registro de accesos, protestas, antecedentes y apoyos de fuerza pública.  
- Generación de reportes estadísticos en tiempo real.  

Esta **landing page** tiene como propósito documentar y presentar:
- Las **buenas prácticas de calidad** aplicadas.  
- Los **instrumentos de control** utilizados.  
- Las **pruebas realizadas** (unitarias, funcionales, de integración y aceptación).  
- Los **estándares mínimos aceptables de calidad** definidos para el proyecto.

## 🧪 Pruebas de Calidad Aplicadas

| Tipo de Prueba | Descripción | Herramienta o Técnica |
|----------------|--------------|------------------------|
| **Unitarias** | Verificación de funciones CRUD (Empresas, Vehículos, Usuarios, etc.) | Insomnia / Postman |
| **Integración** | Pruebas entre el backend (API REST) y frontend (interfaz) | HTTP Requests / JSON |
| **Funcionales** | Validación de flujos de usuario: login, registros y reportes | Escenarios de prueba manual |
| **Rendimiento** | Evaluación de tiempos de respuesta y carga del dashboard | Console API / Lighthouse |
| **Aceptación del Usuario** | Validación final por el cliente | Criterios definidos en el plan de calidad |

---

## 🧾 Instrumentos de Calidad Utilizados

| Instrumento | Descripción | Objetivo |
|--------------|-------------|-----------|
| **Lista de Revisión de Código (Checklist)** | Verificación de estructura, comentarios, convenciones y seguridad. | Garantizar estándares de codificación. |
| **Pruebas Unitarias y de Integración** | Scripts y endpoints validados en Postman. | Verificar consistencia del sistema. |
| **Control de Versiones (Git/GitHub)** | Registro de cambios y seguimiento de commits. | Asegurar trazabilidad del desarrollo. |
| **Documentación Técnica (README / Manuales)** | Documentos explicativos del sistema y sus componentes. | Reducir curva de aprendizaje y facilitar mantenimiento. |
| **Landing Page** | Presentación visual del proceso de calidad. | Comunicar avances y resultados. |

---

## ✅ Estándares Mínimos Aceptables de Calidad

- Cumplimiento del **100% de los requerimientos funcionales** definidos en la fase de análisis.  
- Interfaz **responsiva y accesible** (HTML5, CSS3, Tailwind CSS).  
- Código **documentado, modular y mantenible**.  
- Autenticación **segura con JWT** y contraseñas cifradas con bcrypt.  
- Pruebas unitarias exitosas (CRUD y login).  
- Control de errores y validaciones activas en backend y frontend.  

---

## ⚙️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, Tailwind CSS, JavaScript.
- **Backend (Sistema Principal):** Node.js, Express.js, MongoDB.
- **Control de versiones:** Git y GitHub.
- **Gestión de calidad:** Pruebas con Postman/Insomnia y revisión manual.
- **Despliegue Landing Page:** Netlify.
